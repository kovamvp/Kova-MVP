# Kova Work (mini MVP)

The RM workspace for KOVA, with mock data. React + Vite front end (`web/`), FastAPI on Vercel Functions (`api/index.py` → `backend/`), Neon Postgres as a JSON document store, Groq for the agents and speech.

- `data/` — mock JSON (generated by `scripts/gen_data.py`). Dates are shifted to "this week" when the database is seeded.
- `backend/store.py` — one table of JSON documents; `backend/actions.py` — every RM action (manual or agent-approved) and the outbox; `backend/agent.py` — page agents with approval cards; `backend/llm.py` — Groq gateway with key and model fallback.

Local: `uvicorn api.index:app --port 8000` and `cd web && npm run dev`.
